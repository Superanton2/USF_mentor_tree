# ADR-0002: Бібліотека графа — force-graph

Статус: прийнято · 4 листопада 2026

## Контекст

Потрібен огляд ~1–3 тис. вузлів у стилі Obsidian: фізика, zoom, pan, перетягування, підсвічування, експорт у PNG.

## Рішення

`force-graph` (canvas + d3-force-3d). Sigma.js (WebGL) свідомо відкладено: вона потрібна для десятків тисяч вузлів, а в нас ~1 тис.

Бібліотека схована за адаптером `GraphRenderer` (`packages/web-app/src/graph/`). Компоненти React не викликають її напряму, тож заміна зачепить один файл.

## Деталі, які варто знати

- **Детермінована розкладка.** Симуляція прогрівається (`warmupTicks`), після чого заморожується (`cooldownTicks(0)`). Початкові позиції й випадковість у d3-force детерміновані, тому граф при тих самих даних виглядає однаково. Перетягування вузла ненадовго «будить» симуляцію.
- **Притягання до центру.** Без `forceX/forceY` ~100 окремих дерев розліталися б безкінечно.
- **Перемальовування.** У `force-graph` немає методу `refresh()`, а при `autoPauseRedraw` заморожена симуляція не перемальовується, тому вибір чи наведення не було б видно. Тому `autoPauseRedraw(false)`. Якщо на слабких пристроях це стане проблемою (SPEC 12.3), перевірити заміну на точкове перемальовування.
- **Камера** чекає на першу розкладку (`onEngineStop`): до неї в вузлів немає координат, і `zoomToFit` вписував би порожнечу.
- Типи `d3-force-3d` відсутні, оголошено мінімальний модуль у `src/d3-force-3d.d.ts`.
