# ADR-0003: Статичний сайт і sync-service

Статус: прийнято · 4 листопада 2026

## Рішення

Сайт не має бекенду на запит. `sync-service` читає джерело, будує реліз (`graph.json`) і атомарно перемикає символічне посилання `current`. nginx віддає статичний бандл і поточний реліз.

## Деталі

- Реліз пишеться у тимчасову теку, перейменовується на місце, і лише потім перемикається `current` (rename символічного посилання атомарний).
- Зберігається `RELEASES_TO_KEEP` (5) останніх релізів; поточний ніколи не видаляється. `npm run sync:rollback` перемикає `current` на попередній реліз.
- Звіти імпорту пишуться поза каталогом, який віддає nginx, бо містять імена.
- **Етапи 1–5 (CSV):** галочки «Опублікувати зміни» немає, тому кожен запуск `npm run sync` публікує. Прапорець `--force` приймається, але має сенс лише на етапі 6 (Google-таблиця).

## Наслідки

Дешево, надійно, легко переносити. Зміни з'являються після запуску синхронізації, а не миттєво.
