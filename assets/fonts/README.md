# Шрифти

Apercu Pro — комерційний шрифт, а репозиторій публічний, тому файли `*.woff2` і `*.ttf` у git **не комітяться** (див. `.gitignore`). Це питання ліцензії відкрите, див. `docs/plan.md`.

Потрібні файли (кладуться в `apercu-pro/`):

- `woff2` для сайту: Light, LightItalic, Regular, Italic, Bold, BoldItalic;
- `ttf` для OG-картинок (resvg): Regular, Bold.

Нова людина отримує їх від власника проєкту (архів гайдлайну УСС).
